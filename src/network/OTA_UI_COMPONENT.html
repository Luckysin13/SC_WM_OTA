❓ Troubleshooting

Update Failed or Device Won't Start
  1. Check the error message above
  2. Ensure WiFi connection is stable
  3. Verify device has 50% free LittleFS space
  4. If device won't boot, update via USB cable with PlatformIO
  5. Check serial console (115200 baud) for error details
Update Stuck or Frozen
  1. Click "Cancel Update" button
  2. Wait 5 seconds
  3. Refresh the page
  4. If still stuck, power cycle the device
